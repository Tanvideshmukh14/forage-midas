# ⭐ Midas Core – JPMorgan Chase Virtual Internship Project

Midas Core is a backend service developed as part of the **JPMorgan Chase & Co. Software Engineering Virtual Internship on Forage**. It simulates how enterprise financial systems efficiently handle large numbers of financial transactions using scalable and decoupled architectures.

---

## 🔹 Project Overview

This backend service consumes real-time transaction messages via **Apache Kafka**, processes them asynchronously, and prepares them for validation and storage. The system architecture reflects real-world financial applications commonly used in banking and fintech environments.

---

## 🚀 Key Features

✅ Kafka consumer integration to receive transactions  
✅ Spring Boot–based enterprise backend design  
✅ H2 in-memory database for testing and development  
✅ Spring Data JPA for persistence layer  
✅ Robust test suite using Testcontainers  
✅ Fully modular and scalable microservice-ready architecture  

---
